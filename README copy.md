# Vibe Board Studio

A Day 1 Antigravity IDE activity using only HTML and CSS.

## Repository structure

```text
vibe-board-studio/
├── index.html
├── style.css
├── prompts/
│   ├── 01-personalize.txt
│   ├── 02-create-vibe-board.txt
│   └── 03-fix-layout.txt
├── docs/
│   ├── activity-guide.md
│   └── setup-guide.md
└── examples/
    ├── sample-board.html
    └── sample-board.css
```

Start with `index.html`, then use the prompts in order.

The `examples` folder contains a neutral sample for reference.
