# Vibe Board Studio Activity Guide

## Activity flow

1. Install and open Antigravity IDE.
2. Review the Explorer, Editor, Terminal, Agent, and Preview sections.
3. Practice `pwd`, `ls`, `mkdir`, `cd`, and `cd ..`.
4. Clone or download this repository.
5. Open `index.html` and preview the starter page.
6. Use `prompts/01-personalize.txt`.
7. Review the proposed changes before applying them.
8. Preview the personalized plain page.
9. Use `prompts/02-create-vibe-board.txt`.
10. Review the plan and confirm that it describes one asymmetrical collage board.
11. Apply the changes and preview the result.
12. Use `prompts/03-fix-layout.txt` only if the page becomes a dashboard or grid.

## Technology limits

This activity uses only HTML and CSS.

Do not add JavaScript, React, npm packages, backend code, or external libraries.
