# Setup Guide

## Clone from GitHub

```bash
git clone YOUR_REPOSITORY_URL
cd vibe-board-studio
```

## Useful terminal commands

```bash
pwd
ls
mkdir practice-folder
cd practice-folder
cd ..
```

## Recommended Antigravity settings

- Agent Auto-Fix Lints: Off
- Auto Execution: Ask First or Manual Approval
- Review Policy: Ask First or Require Review
- Suggestions in Editor: On

## Preview

Open `index.html` directly in a browser, or use a local preview option available in the IDE.
